# Beam Designer

Beam Designer is a Tkinter desktop app for analyzing simply supported and cantilever beams with point and uniform loads. It calculates reactions, shear, moment, and deflection, checks bending and deflection limits, and displays diagrams. Beam designs can be saved and reopened, with results exportable to CSV and PDF.

## Install

Requires Python 3.10 or later. Install the third-party packages:

```powershell
python -m pip install numpy matplotlib
```

Tkinter is included with most standard Python installations. On Linux, install the system Tk package if needed (for example, `python3-tk`).

## Run

```powershell
python app.py
```
